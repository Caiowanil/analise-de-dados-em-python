📱 Análise de Dados sobre Redes Sociais no Brasil

Projeto acadêmico de análise de dados desenvolvido em Python para explorar e comparar informações sobre o uso das redes sociais no Brasil, com foco no Instagram, TikTok, WhatsApp e YouTube.

📌 Sobre o projeto

O objetivo deste projeto é compreender melhor como as redes sociais fazem parte do cotidiano dos brasileiros, utilizando dados de diferentes fontes para identificar características do público e padrões de utilização das plataformas.

A análise reúne informações e apresenta os resultados por meio de gráficos e de um dashboard interativo, facilitando a visualização e a comparação dos dados entre as redes sociais.

🎯 Objetivos
Analisar características do público das principais redes sociais.
Observar a distribuição dos usuários por faixa etária e sexo.
Explorar diferenças regionais no Brasil.
Identificar informações sobre horários de acesso e frequência de utilização.
Visualizar e comparar os dados por meio de gráficos e de um dashboard interativo.
Praticar técnicas de análise e visualização de dados com Python.

🚀 Como executar o projeto
1. Pré-requisitos

É necessário ter o Python instalado no computador.

2. Clone o repositório
bash
git clone URL_DO_SEU_REPOSITORIO


Substitua URL_DO_SEU_REPOSITORIO pelo endereço do seu repositório no GitHub.

3. Entre na pasta do projeto
bash
cd NOME_DA_PASTA


Substitua NOME_DA_PASTA pelo nome da pasta criada no seu computador.

4. Instale as dependências
bash
pip install -r requirements.txt

5. Execute a análise
bash
python analise_redes_sociais.py

6. Visualize os resultados

Após a execução, abra o arquivo index.html em um navegador para visualizar o dashboard e explorar os gráficos gerados.

📚 Fontes dos dados

As informações foram reunidas a partir de relatórios, pesquisas e publicações relacionadas ao uso das redes sociais e ao comportamento digital no Brasil.

Entre as fontes consultadas estão:

DataReportal — relatórios sobre o cenário digital, incluindo o Brasil.
Cetic.br — pesquisas sobre o uso das tecnologias de informação e comunicação.
NapoleonCat — estatísticas relacionadas a usuários de redes sociais.
Affect Group — informações sobre o público do TikTok.
Opinion Box — pesquisas sobre comportamento e hábitos dos consumidores.
mLabs — conteúdos e estudos sobre redes sociais e marketing digital.
Canaltech e Teletime — publicações complementares sobre tecnologia e comportamento digital.
⚠️ Limitações dos dados

As fontes consultadas podem utilizar períodos, metodologias e definições de público diferentes. Por esse motivo, nem todos os indicadores podem ser comparados diretamente.

Em alguns gráficos, foram utilizados indicadores aproximados (proxies) para representar aspectos do comportamento digital quando não havia dados públicos específicos para determinada plataforma ou grupo.

Esses indicadores não devem ser interpretados como medidas diretas de utilização de uma rede social. Os resultados devem ser analisados considerando as fontes e as limitações de cada informação.
